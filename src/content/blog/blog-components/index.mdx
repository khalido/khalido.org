:::ai
CodeRunner built-ins: `Plot`, `Inputs`, `csvParse`/`tsvParse`/`autoType`, and cached fetch helpers `csv(url)`, `tsv(url)`, `json(url)`, `text(url)` — dragging the slider above re-runs the block without refetching the CSV. Multi-line code belongs in a colocated `.js` file imported with `?raw`: MDX strips leading indentation from multi-line template-literal props, so inline ``code={`...`}`` loses its formatting. Pass build-time values into the code with `vars`, e.g. `vars={{ brentUrl }}`.
:::
